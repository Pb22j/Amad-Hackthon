# Archived implementations

These directories are retained for historical reference only:

- `nafi-finance-ui/` is the unused dashboard-card prototype superseded by `components/nafi/`.
- `vite-voice-ui/` is the earlier Vite voice client superseded by the root Next.js app and
  `components/chat/`.

The active application excludes this directory from TypeScript compilation. Do not add new
production imports here.
